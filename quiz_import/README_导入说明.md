## 飞书网页导入（最快）

1. 打开飞书多维表格「题目」表
2. 右上角 **导入** → 选择 `飞书导入_民法物权编_079-084.xlsx`
3. 映射列名到表字段（名称一致可自动匹配）
4. 确认导入，刷新前端验证

若表尚未建立，按 xlsx 中「导入说明」页建字段。
