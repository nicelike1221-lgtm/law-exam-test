⚙️ 如何启用

  1. 1

    确认 Garmin 凭据

    检查 C:/Users/mushr/.workbuddy/mcp.json 中已有 garmin-cn 服务器，并填写了你的 Garmin 中国区邮箱与密码。

  2. 2

    启动开发服务器

    运行 npm run dev，Node 会自动启动 Garmin 数据后端（garmin_chat_backend.py）。

  3. 3

    开始对话

    在下方对话框输入问题，AI 教练会直接调用 Garmin 数据并在此页面回复你。
