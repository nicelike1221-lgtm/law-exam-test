# 上线前检查清单

> 在推送到 GitHub / 部署 Cloudflare 之前逐项确认。

## 本地检查

- [ ] `npm run check:feishu` 显示 ✅ 并通过
- [ ] `npm run dev` 启动后，http://localhost:8080 能打开
- [ ] 密码 `2026` 能进入
- [ ] 题目数量与飞书一致
- [ ] 作答后能判分、显示解析
- [ ] 答错后错题本数量 +1
- [ ] 错题本页能重练、能移除、能清空

## Git 检查

- [ ] 项目已 `git init` 并至少提交一次
- [ ] `.env` 不在仓库中（执行 `git ls-files | findstr .env` 无结果）
- [ ] `.env.example` 在仓库中，且字段完整
- [ ] 已设置远程 origin 并推送到 GitHub

## Cloudflare Pages 检查

- [ ] 已创建 Pages 项目并连接 GitHub 仓库
- [ ] Framework preset = **None**
- [ ] Build command = 空
- [ ] Output directory = `/`
- [ ] 已添加 4 个环境变量：
  - `FEISHU_APP_ID`
  - `FEISHU_APP_SECRET`
  - `FEISHU_BASE_ID`
  - `FEISHU_QUESTION_TABLE_ID`
- [ ] 添加/修改环境变量后已 **Retry deployment**
- [ ] 部署成功，拿到 `*.pages.dev` 域名

## 线上验收

- [ ] 线上密码能进入
- [ ] 线上题目数量 = 飞书有效题数
- [ ] 作答判分正常
- [ ] 错题本功能正常
- [ ] 飞书改一道题 → 刷新线上页面 → 内容已更新
- [ ] 浏览器控制台无 401 / CORS / 500 报错

## 安全提醒

- **不要把 `.env` 上传到 GitHub**
- **不要把 App Secret 贴到公开页面或聊天记录**
- 生产环境建议关闭 `GET /api/token` 调试接口（删除 functions/api/[[path]].js 中的 `token` 分支）
