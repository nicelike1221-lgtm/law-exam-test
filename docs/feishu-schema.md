# 飞书多维表格字段设计（题目表）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 题目ID | 文本 | 唯一键，如 `minfa-079` |
| 科目 | 单选 | 民法 / 刑法 / 民诉… |
| 编章 | 文本 | 如：第二编 物权编 |
| 章节 | 文本 | 章/节路径 |
| 题型 | 单选 | 单选 / 多选 / 判断 |
| 题干 | 多行文本 | 不含选项 |
| 选项A | 文本 | |
| 选项B | 文本 | |
| 选项C | 文本 | |
| 选项D | 文本 | |
| 选项E | 文本 | 可空 |
| 答案 | 文本 | 单选 `A`；多选 `ABD`（无分隔） |
| 解析 | 多行文本 | |
| 考点 | 文本 | 中文分号分隔 |
| 难度 | 单选 | 低 / 中 / 高 |
| 来源 | 文本 | 真题出处 |
| 年份 | 文本 | 如 2025 |
| 状态 | 单选 | 已发布 / 草稿 |
| 排序 | 数字 | 可用原书题号 |
| 备注 | 文本 | 内部备注 |
