# 接飞书操作步骤（让网页显示 10 题）

目标：把 `D:\测试` 从本地 sample（2 题）切到飞书多维表格（你已导入的 10 题）。

---

## 第 0 步：确认现状

如果打开 http://localhost:8080/api/health 看到：

```json
{"hasFeishu": false, "mode": "sample"}
```

说明**还没配飞书密钥**，网页只会读 `data/questions.sample.json`（2 题）。

---

## 第 1 步：准备 4 个值

| 变量 | 去哪拿 |
|------|--------|
| `FEISHU_APP_ID` | 飞书开放平台 → 你的企业自建应用 → **凭证与基础信息** → App ID |
| `FEISHU_APP_SECRET` | 同上 → App Secret（点查看/重置） |
| `FEISHU_BASE_ID` | 打开多维表格，浏览器地址栏类似 `.../base/<这一段>`；或在表格分享链接里找 |
| `FEISHU_QUESTION_TABLE_ID` | 打开「题目」数据表，URL 或表信息里形如 `tblxxxxxxxxxx` |

### 权限必须做（最容易漏）

1. 开放平台应用开通权限（至少）：
   - 查看、评论、编辑和管理多维表格（或最小只读 bitable 相关权限）
2. **发布**应用权限版本
3. 打开你的多维表格 → 右上角「…」→ **添加文档应用 / 添加应用** → 选中该应用  
   （不添加，token 能拿但读表会失败）

---

## 第 2 步：创建本地 `.env`

在 `D:\测试` 下：

1. 复制文件：
   - 把 `.env.example` 复制一份，改名为 `.env`
2. 用记事本打开 `.env`，改成真实值，例如：

```env
FEISHU_APP_ID=cli_xxxxxxxxxxxx
FEISHU_APP_SECRET=xxxxxxxxxxxxxxxx
FEISHU_BASE_ID=你的BaseToken
FEISHU_QUESTION_TABLE_ID=tblxxxxxxxxxxxx
PORT=8080
```

注意：

- 等号两边**不要空格**
- 值**不要**加引号（一般不需要）
- `.env` 已被 gitignore，不会提交到 GitHub

PowerShell 一键复制：

```powershell
cd D:\测试
Copy-Item .env.example .env
notepad .env
```

Git Bash：

```bash
cd /d/测试
cp .env.example .env
# 再用编辑器改 .env
```

---

## 第 3 步：跑连通性检查

```bash
cd /d/测试
node scripts/check-feishu.js
```

期望看到：

- token 获取成功
- 读到原始记录 ≥ 10 条

若失败，按脚本提示排查 AppID / 权限 / Base 授权 / TableID。

---

## 第 4 步：重启本地服务

旧进程先停掉（终端里 `Ctrl+C`），再：

```bash
cd /d/测试
npm run dev
```

启动日志应出现：

```text
数据模式: 飞书多维表格
```

而不是「本地 sample JSON」。

---

## 第 5 步：验收

1. 打开 http://localhost:8080/api/health  
   - `hasFeishu: true`
   - `mode: "feishu"`

2. 打开 http://localhost:8080/api/questions  
   - `source: "feishu"`
   - `total: 10`（或接近 10）

3. 打开 http://localhost:8080  
   - 密码：`2026`
   - 顶部/列表应显示约 10 题

---

## 如果 total 仍 < 10

前端默认只显示 **状态=已发布** 的题，且必须有 **题目ID + 题干**：

| 检查项 | 要求 |
|--------|------|
| 字段名 | 必须叫 `题目ID`、`题干`、`状态`…（与导入表一致，不能多空格） |
| 状态 | 填 `已发布`；草稿不显示 |
| 题目ID | 非空 |
| 题干 | 非空 |
| 科目筛选 | 页面若选了某科目，只显示该科目 |

可临时看全部原始数：跑 `node scripts/check-feishu.js`

---

## 常见报错对照

| 现象 | 原因 |
|------|------|
| 仍是 2 题 / mode=sample | 没有 `.env` 或没重启服务 |
| 换 token 失败 | AppID/Secret 错，或应用未启用 |
| 读表失败 code=91403 等 | 应用未加入该 Base，或无 bitable 权限 |
| 读到 0 条 | TableID 指错表 |
| 读到 10 条但网页更少 | 状态不是「已发布」，或题目ID/题干为空 |
